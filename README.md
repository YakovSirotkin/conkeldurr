# conkeldurr

I have used the queue-over-database approach in many projects since 2007. 
In 2022, I created an open-source library for it. In 2023, 
I worked on an AWS project using Amazon SQS, and I must say that Amazon SQS 
offers a great choice of parameters and default values.

This project is designed to implement a queue-over-database solution 
that supports both exponential backoff and configurations inspired by Amazon SQS.
